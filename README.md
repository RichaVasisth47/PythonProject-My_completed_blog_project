# 📝 My Completed Blog Project

A dynamic blog web application built with Python, Flask, and SQLAlchemy that enables users to manage and publish blog posts seamlessly with a clean user interface.

---

## 🚀 Features

- **Post Management:** Create, read, update, and delete (CRUD) blog posts dynamically.
- **Database Integration:** Uses SQLite and SQLAlchemy to securely store and persist article data.
- **Clean UI:** Styled with a modern layout for an optimal reading and writing experience.
- **Routing & Templates:** Utilizes Flask templates (`Jinja2`) for smooth navigation across pages.

---

## 🛠️ Built With

- **Python** (Backend Logic)
- **Flask** (Web Framework)
- **Flask-SQLAlchemy** (Database & ORM)
- **SQLite** (Database storage)
- **HTML5 / CSS3 / Jinja2**

## ⚙️️ Installation & Setup

Follow these steps to run the project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/RichaVasisth47/PythonProject-My_completed_blog_project.git](https://github.com/RichaVasisth47/PythonProject-My_completed_blog_project.git)
   cd PythonProject-My_completed_blog_project

Install dependencies:
Bash
pip install -r requirements.txt

Run the application:
Bash
python main.py

Open in browser:
Visit http://127.0.0.1:5000 to view and interact with the blog.
